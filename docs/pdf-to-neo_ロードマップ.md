- **コミット運用**: スキル・生成器は git で共有する。案件データは `NEO_check`（各 PC のローカル）。ADDATA は各 PC のコグニのもの。

## 5. 進め方（おすすめの順）

1. **金額に影響する規則の未確定は W90b の連動加算（1-A）だけ**（該当組合せは run_case が ★ で知らせる）。次は工場から届いた実 NEO を `NEO_check` に置いて総当たりの対象を増やす。
2. **工場 NEO と過去案件 NEO を集める**（2 節）。届いたものから `NEO_check` に置き、`verify_all` の対象に追加。
3. 集まった NEO を `tests/audit_cogni_files.py` の総当たりに加え、W90b（連動加算）と同じ組合せが出たら規則を同定して生成器に反映（1-3〜1-6 は確認済み。追加の裏取りに使う）。
4. 10 案件を超えたら **3-1 学習辞書**、その後 3-2〜3-5（OCR・報告書の改善）。

## 6. 参考（今回の解析で分かった小さな事実）

- 装備の変更は「見積結果 → その他 → 装備バリエーション変更」。再検索で部品番号・価格・工賃が更新され、`*`/`#`・個数・保留は残せる。
- コグニが再検索後に保存する PartsNo は 17 桁の空白埋め、複数候補は末尾 `*`。Time は浮動小数のまま（0.30000000000000004）。
- 24.DB は ADAS 再設定の対応表。10.DB は装備名。12.DB の注記行「…指数が設定されておりませんので弊社独自の参考値…」が暫定指数 `$` の出どころ。
- COM.CAB の 53 ファイルは MSZIP なので Python の zlib で展開できる（Explore 調査 2026-09-08）。
